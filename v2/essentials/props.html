Essentials

Props

Every prop of the FunctionalCalendar component, with type, default and behavior.

Props use camelCase in JavaScript and kebab-case in templates, so isDatePicker becomes is-date-picker. A prop you leave out keeps the default shown here.

Value and configuration

PropTypeDefaultDescription
valueObjectnoneThe calendar state. Bind it with v-model. Change it from outside to preselect dates.
configsObjectnoneAll options as one object. When set, the calendar skips every individual prop that has a configs key.
newCurrentDateDatetodayThe month to show first.

configs

Any option in the tables below can be a key of configs, except value, newCurrentDate, canClearRange, displayTimeInput, activeHours, activeMinutes, borderColor, alwaysUseDefaultClasses and configs itself. Those keep working as props next to configs.

Any other prop you pass next to configs is ignored. Four options are also read straight from the prop in parts of the component: isMultipleDateRange, showWeekNumbers, isSeparately and changeYearStep. Set each of these in configs and as a prop.

{
    isDateRange: true,
    sundayStart: true,
    limits: { min: '1/10/2026', max: '31/12/2026' }
}

Selection modes

PropTypeDefaultDescription
isDatePickerBooleanfalsePick one date. The result is selectedDate.
isMultipleDatePickerBooleanfalsePick any number of dates. The result is selectedDates.
isDateRangeBooleanfalsePick one range. The result is dateRange.
isMultipleDateRangeBooleanfalsePick several ranges. Use it together with isDateRange. The result is multipleDateRange.
canClearRangeBooleanfalseShow a Clear Range button in the footer of a range calendar.
minSelDaysNumber or BooleanfalseShortest range, in days. Both end days count.
maxSelDaysNumber or BooleanfalseLongest range, in days. Both end days count.

Date format

PropTypeDefaultDescription
dateFormatStringdd/mm/yyyy hh:MMThe format of every date string.
placeholderString or Booleanthe date formatPlaceholder of the date inputs in modal mode.

Use dd, mm and yyyy joined by /, - or .. Add a time part after a space: HH:MM, HH:mm, hh:MM or hh:mm. Any other time part fails prop validation.

Layout

PropTypeDefaultDescription
isMultipleBooleanfalseShow more than one calendar. Set the number with calendarsCount.
calendarsCountNumber1How many calendars to show when isMultiple is on.
isSeparatelyBooleanfalseLet each calendar change month on its own.
isModalBooleanfalseShow an input and open the calendar in a popover when it gains focus.
isTypeableBooleanfalseLet users type dates into the modal inputs.
isAutoCloseableBooleanfalseClose the modal calendar once a selection is complete.
isDarkBooleanfalseUse the dark theme.
isLayoutExpandableBooleanfalseFit the height to the weeks in the month. By default every calendar reserves six rows.
titlePositionStringcenterMonth and year title alignment: left, center or right.
arrowsPositionStringspace-betweenNavigation arrow placement: left, right or space-between.
showWeekNumbersBooleanfalseShow the week number before each week.
borderColorStringemptyCSS color for the line beside the week numbers.
transitionBooleantrueAnimate month changes.
hiddenElementsArray[]Parts to hide: month (the title), dayNames and leftAndRightDays (days of neighboring months).
alwaysUseDefaultClassesBooleanfalseKeep the default day class vfc-span-day when you fill the day slot.

Navigation

PropTypeDefaultDescription
changeMonthFunctionBooleanfalseOpen a month picker when users click the month title.
changeYearFunctionBooleanfalseOpen a year picker when users click the year title.
changeMonthStepNumber1Months to move on each arrow click.
changeYearStepNumber3Years to move on each arrow click inside the year picker.

Availability and marking

PropTypeDefaultDescription
limitsObject or BooleanfalseAn { min, max } pair of date strings. Days outside it are disabled and the arrows stop at its months.
disabledDatesArray[]Date strings that users cannot pick. Also accepts beforeToday and afterToday.
enabledDatesArray[]When not empty, only these dates can be picked. Accepts the same keywords.
disabledDayNamesArray[]Weekdays users cannot pick, by name from dayNames, for example ['Sa', 'Su'].
markedDatesArray[]Date strings to highlight. Or objects like { date: '24/4/2026', class: 'my-class' } to add a CSS class.
markedDateRangeObject or Arraystart and end unsetA { start, end } span to highlight, or an array of spans.

Names

PropTypeDefaultDescription
dayNamesArrayMo to SuSeven day names, Monday first.
monthNamesArrayJanuary to DecemberTwelve month names, used in the title.
shortMonthNamesArrayJan to DecTwelve short names, used in the month picker.
sundayStartBooleanfalseStart the week on Sunday. Keep dayNames Monday first. The calendar moves the last name to the front.

Time picker

PropTypeDefaultDescription
withTimePickerBooleanfalseOpen the time picker after a day click.
displayTimeInputBooleanfalseShow the selected time in the single date input of a modal calendar.
activeHoursArray0 to 23Hours users can choose.
activeMinutesArray0 to 59Minutes users can choose.

Example

<FunctionalCalendar
    v-model="calendarData"
    :is-date-range="true"
    :is-multiple="true"
    :calendars-count="2"
    :limits="{ min: '1/10/2026', max: '31/12/2026' }"
    :disabled-day-names="['Sa', 'Su']"
    :min-sel-days="2"
    :max-sel-days="14"
    :can-clear-range="true"
/>
