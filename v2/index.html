Vue Functional Calendar

Lightweight calendar and datepicker component for Vue 2.

Date picker, date range, multiple calendars, time picker and modal mode, with no third-party dependencies.

Get startedGitHub
These docs cover 2.x for Vue 2. Vue 3 users: see the 3.x docs.

Why Vue Functional Calendar?

    Date picker
    Pick one date or several, in an inline calendar or a modal.
    Date range
    Select a range, or many ranges, with minimum and maximum lengths.
    Multiple calendars
    Show two or more months side by side, linked or independent.
    Time picker
    Add hours and minutes to a single date or to a range.
    Limits and availability
    Disable dates, weekdays or whole spans, or allow only a list of dates.
    Customizable
    Replace the day cell, arrows, footer and inputs with slots.
