Getting Started

Installation

Install Vue Functional Calendar 2.x and register it in a Vue 2 app.

Vue Functional Calendar 2.x needs Vue 2.6 or later, because scoped slots and the compiled bundle use the 2.6 slot syntax. For Vue 3, use the 3.x line.

Install

npm install vue-functional-calendar@^2.10.0 --save

yarn add vue-functional-calendar@^2.10.0

The package bundles its own styles. There is no CSS file to import.

Register globally

Vue.use registers the FunctionalCalendar component in every template. The second argument sets defaults for every calendar.

import Vue from 'vue'
import FunctionalCalendar from 'vue-functional-calendar'

Vue.use(FunctionalCalendar, {
    dayNames: ['Mo', 'Tu', 'We', 'Th', 'Fr', 'Sa', 'Su']
})

Global options accept any key of the configs object.

Register in a component

import { FunctionalCalendar } from 'vue-functional-calendar'

export default {
    components: {
        FunctionalCalendar
    }
}

Use from a CDN

The UMD build exposes a FunctionalCalendar global.

<script src="https://unpkg.com/vue@2"></script>
<script src="https://unpkg.com/vue-functional-calendar@2"></script>

<div id="app">
    <functional-calendar v-model="calendarData" :is-date-picker="true"></functional-calendar>
</div>

<script>
    Vue.use(FunctionalCalendar)

    new Vue({
        el: '#app',
        data: {
            calendarData: {}
        }
    })
</script>

TypeScript

The package ships index.d.ts. Both the named export and the default plugin export are typed.
