## Basic calendar

Bind the calendar with `v-model`. The bound object holds the whole calendar state.

```vue
<template>
    <FunctionalCalendar v-model="calendarData" />
</template>

<script>
import { FunctionalCalendar } from 'vue-functional-calendar'

export default {
    components: { FunctionalCalendar },
    data() {
        return {
            calendarData: {}
        }
    }
}
</script>
```

Without a selection mode, the calendar only displays dates. Turn on one mode to let users pick.

## Selection modes

| Prop | What users pick |
| --- | --- |
| `is-date-picker` | One date. |
| `is-multiple-date-picker` | Any number of single dates. |
| `is-date-range` | One range with a start and an end. |
| `is-multiple-date-range` | Several ranges, together with `is-date-range`. |

```vue
<FunctionalCalendar v-model="calendarData" :is-date-range="true" />
```

## Read the selected value

`v-model` receives an object. Which keys matter depends on the mode.

| Mode | Where the value lives |
| --- | --- |
| Date picker | `selectedDate`, a string in `date-format`. With the time picker, also `selectedDateTime`, `selectedHour` and `selectedMinute`. |
| Multiple date picker | `selectedDates`, an array of `{ date, dateTime, hour, minute }` objects. |
| Date range | `dateRange.start` and `dateRange.end`, both strings. |
| Multiple date range | `multipleDateRange`, an array of `{ start, end }` objects. |

`currentDate` is a `Date` for the month on display.

```js
{
    currentDate: new Date(2026, 9, 17),
    selectedDate: false,
    selectedDateTime: false,
    selectedHour: '00',
    selectedMinute: '00',
    selectedDatesItem: '',
    selectedDates: [],
    dateRange: { start: '3/10/2026', end: '9/10/2026' },
    multipleDateRange: []
}
```

Dates follow `date-format`, which defaults to `dd/mm/yyyy`. Days and months in values the calendar produces have no leading zero.

## Configure with props

Pass any option as a prop. Use kebab-case in templates.

```vue
<FunctionalCalendar
    v-model="calendarData"
    :is-date-picker="true"
    :sunday-start="true"
    date-format="dd/mm/yyyy"
    @changedMonth="onChangedMonth"
    @changedYear="onChangedYear"
/>
```

## Configure with an object

The `configs` prop takes the same options as one object. This suits shared or stored settings.

```vue
<template>
    <FunctionalCalendar v-model="calendarData" :configs="calendarConfigs" />
</template>

<script>
export default {
    data() {
        return {
            calendarData: {},
            calendarConfigs: {
                sundayStart: false,
                dateFormat: 'dd/mm/yyyy',
                isDatePicker: false,
                isDateRange: true
            }
        }
    }
}
</script>
```

::warning
When `configs` is set, the calendar ignores the matching individual props. Pass `isMultipleDateRange` and `showWeekNumbers` as props, because parts of the template read them from the prop directly.
::

Option precedence, lowest to highest: built-in defaults, options given to `Vue.use`, then `configs` or individual props.
