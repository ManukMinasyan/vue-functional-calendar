Props use camelCase in JavaScript and kebab-case in templates, so `isDatePicker` becomes `is-date-picker`. A prop you leave out keeps the default shown here.

## Value and configuration

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `value` | `Object` | none | The calendar state. Bind it with `v-model`. Change it from outside to preselect dates. |
| `configs` | `Object` | none | All options as one object. When set, the calendar skips every individual prop that has a `configs` key. |
| `newCurrentDate` | `Date` | today | The month to show first. |

### configs

Any option in the tables below can be a key of `configs`, except `value`, `newCurrentDate`, `canClearRange`, `displayTimeInput`, `activeHours`, `activeMinutes`, `borderColor`, `alwaysUseDefaultClasses` and `configs` itself. Those keep working as props next to `configs`.

Any other prop you pass next to `configs` is ignored. Four options are also read straight from the prop in parts of the component: `isMultipleDateRange`, `showWeekNumbers`, `isSeparately` and `changeYearStep`. Set each of these in `configs` and as a prop.

```js
{
    isDateRange: true,
    sundayStart: true,
    limits: { min: '1/10/2026', max: '31/12/2026' }
}
```

## Selection modes

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `isDatePicker` | `Boolean` | `false` | Pick one date. The result is `selectedDate`. |
| `isMultipleDatePicker` | `Boolean` | `false` | Pick any number of dates. The result is `selectedDates`. |
| `isDateRange` | `Boolean` | `false` | Pick one range. The result is `dateRange`. |
| `isMultipleDateRange` | `Boolean` | `false` | Pick several ranges. Use it together with `isDateRange`. The result is `multipleDateRange`. |
| `canClearRange` | `Boolean` | `false` | Show a Clear Range button in the footer of a range calendar. |
| `minSelDays` | `Number` or `Boolean` | `false` | Shortest range, in days. Both end days count. |
| `maxSelDays` | `Number` or `Boolean` | `false` | Longest range, in days. Both end days count. |

## Date format

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `dateFormat` | `String` | `dd/mm/yyyy hh:MM` | The format of every date string. |
| `placeholder` | `String` or `Boolean` | the date format | Placeholder of the date inputs in modal mode. |

Use `dd`, `mm` and `yyyy` joined by `/`, `-` or `.`. Add a time part after a space: `HH:MM`, `HH:mm`, `hh:MM` or `hh:mm`. Any other time part fails prop validation.

## Layout

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `isMultiple` | `Boolean` | `false` | Show more than one calendar. Set the number with `calendarsCount`. |
| `calendarsCount` | `Number` | `1` | How many calendars to show when `isMultiple` is on. |
| `isSeparately` | `Boolean` | `false` | Let each calendar change month on its own. |
| `isModal` | `Boolean` | `false` | Show an input and open the calendar in a popover when it gains focus. |
| `isTypeable` | `Boolean` | `false` | Let users type dates into the modal inputs. |
| `isAutoCloseable` | `Boolean` | `false` | Close the modal calendar once a selection is complete. |
| `isDark` | `Boolean` | `false` | Use the dark theme. |
| `isLayoutExpandable` | `Boolean` | `false` | Fit the height to the weeks in the month. By default every calendar reserves six rows. |
| `titlePosition` | `String` | `center` | Month and year title alignment: `left`, `center` or `right`. |
| `arrowsPosition` | `String` | `space-between` | Navigation arrow placement: `left`, `right` or `space-between`. |
| `showWeekNumbers` | `Boolean` | `false` | Show the week number before each week. |
| `borderColor` | `String` | empty | CSS color for the line beside the week numbers. |
| `transition` | `Boolean` | `true` | Animate month changes. |
| `hiddenElements` | `Array` | `[]` | Parts to hide: `month` (the title), `dayNames` and `leftAndRightDays` (days of neighboring months). |
| `alwaysUseDefaultClasses` | `Boolean` | `false` | Keep the default day class `vfc-span-day` when you fill the day slot. |

## Navigation

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `changeMonthFunction` | `Boolean` | `false` | Open a month picker when users click the month title. |
| `changeYearFunction` | `Boolean` | `false` | Open a year picker when users click the year title. |
| `changeMonthStep` | `Number` | `1` | Months to move on each arrow click. |
| `changeYearStep` | `Number` | `3` | Years to move on each arrow click inside the year picker. |

## Availability and marking

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `limits` | `Object` or `Boolean` | `false` | An `{ min, max }` pair of date strings. Days outside it are disabled and the arrows stop at its months. |
| `disabledDates` | `Array` | `[]` | Date strings that users cannot pick. Also accepts `beforeToday` and `afterToday`. |
| `enabledDates` | `Array` | `[]` | When not empty, only these dates can be picked. Accepts the same keywords. |
| `disabledDayNames` | `Array` | `[]` | Weekdays users cannot pick, by name from `dayNames`, for example `['Sa', 'Su']`. |
| `markedDates` | `Array` | `[]` | Date strings to highlight. Or objects like `{ date: '24/4/2026', class: 'my-class' }` to add a CSS class. |
| `markedDateRange` | `Object` or `Array` | start and end unset | A `{ start, end }` span to highlight, or an array of spans. |

## Names

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `dayNames` | `Array` | `Mo` to `Su` | Seven day names, Monday first. |
| `monthNames` | `Array` | `January` to `December` | Twelve month names, used in the title. |
| `shortMonthNames` | `Array` | `Jan` to `Dec` | Twelve short names, used in the month picker. |
| `sundayStart` | `Boolean` | `false` | Start the week on Sunday. Keep `dayNames` Monday first. The calendar moves the last name to the front. |

## Time picker

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `withTimePicker` | `Boolean` | `false` | Open the time picker after a day click. |
| `displayTimeInput` | `Boolean` | `false` | Show the selected time in the single date input of a modal calendar. |
| `activeHours` | `Array` | `0` to `23` | Hours users can choose. |
| `activeMinutes` | `Array` | `0` to `59` | Minutes users can choose. |

## Example

```vue
<FunctionalCalendar
    v-model="calendarData"
    :is-date-range="true"
    :is-multiple="true"
    :calendars-count="2"
    :limits="{ min: '1/10/2026', max: '31/12/2026' }"
    :disabled-day-names="['Sa', 'Su']"
    :min-sel-days="2"
    :max-sel-days="14"
    :can-clear-range="true"
/>
```
