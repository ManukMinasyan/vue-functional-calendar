The calendar follows the ARIA date grid pattern. Screen readers get names, states and a single tab stop per month. The [keyboard page](/essentials/keyboard) lists every key.

## Grid semantics

| Part | Markup |
| --- | --- |
| Month | `role="grid"`, named by the month and year, such as "October 2026" |
| Week | `role="row"` |
| Day | `role="gridcell"` with a full date as `aria-label`, such as "Thursday, 15 October 2026" |
| Week number | `role="rowheader"` |
| Day name row | `aria-hidden="true"`, because each day already has a full date label |
| Filler rows | `role="presentation"` and `aria-hidden="true"` |

Day labels and the month name use the calendar's own names and the locale you set, always in the Gregorian calendar. Custom `monthNames` appear in the labels.

## Day states

- `aria-selected` is set on days when the calendar selects something. It is absent on a display-only calendar.
- `aria-disabled="true"` marks days blocked by `limits`, `disabledDates`, `enabledDates` or `disabledDayNames`.
- Today has `aria-current="date"` and "Today" at the end of its label. The word comes from `labels.today`.
- The first and last day of a date range end their label with "range start" or "range end", from `labels.rangeStart` and `labels.rangeEnd`. A one day range gets both.
- A day in a numbered range has its range number added to the label, such as "Thursday, 15 October 2026, Range 2, range start". The word comes from `labels.range`. The number badge drawn on the day is `aria-hidden` and comes from a `data-number` attribute, so the visible text of the day is only its number.
- Days in a multiple date range carry `aria-keyshortcuts="Delete"`.

## Roving focus

Each month has one tab stop, so Tab crosses the grid in one step. The stop sits on the day you last focused, then on the selected day, then on today, then on the first enabled day. The other days have `tabindex="-1"` and are reached with the arrow keys.

Focus stays on the same day when the calendar re-renders, for example after a month change. If that day leaves the screen, focus goes to the tab stop of the same month.

## Month changes

A visually hidden `aria-live="polite"` region holds the visible months, such as "October 2026" or "October 2026, November 2026". It updates on every month change, so a screen reader announces the new month. The calendar's root element is not focusable: the tab stops are the inputs, the controls and the grid.

## Controls

| Control | Markup |
| --- | --- |
| Arrows | `<button>` with the label from `labels.previousMonth` or `labels.nextMonth`, and `aria-disabled` at a limit |
| Month and year titles | `role="button"`, `tabindex="0"` and `aria-expanded`, when the pickers are on |
| Picker items | `role="button"` with `aria-pressed` on the current one |
| Presets | A `role="group"` named by `labels.quickRanges`, holding buttons with `aria-pressed` and `aria-disabled` |
| Clear button | `role="button"` with `aria-disabled` when there is nothing to clear |
| Time picker | Two `role="listbox"` lists named by `labels.hour` and `labels.minute`, with `role="option"` items and `aria-selected` |
| Time picker close | `role="button"` labeled by `labels.close` |
| Tags input of the multiple date picker | An input named by `labels.addDate`, and one `<button>` per date labeled `labels.removeDate` plus the date. Removing a date returns focus to the input |

Arrow slots with your own button or link keep their own focus and semantics.

## Modal calendars

In modal mode, the calendar is a `role="dialog"` named by `labels.calendar`. Its inputs are `role="combobox"` with `aria-haspopup="dialog"`, an `aria-controls` that points at the dialog, an `aria-expanded` that tracks it, and an `aria-label` and `title` from `labels.date`, `labels.startDate` or `labels.endDate`. Inputs you render in the `datePickerInput` and `dateRangeInputs` slots are your markup, so add these attributes yourself.

Focus follows these rules:

- Focusing an input, or pressing ArrowDown or Alt+ArrowDown on it, opens the calendar.
- Escape closes the calendar and returns focus to the input that opened it.
- Selecting a day with the keyboard in an auto-closing calendar returns focus to the input.
- Focus leaving the calendar and its inputs closes it.
- Escape inside a month or year picker, or the time picker, closes only that layer.

## Focus ring

Focused controls show a 2px outline in `--vfc-focus`. It defaults to the primary color, so change it if your primary color has low contrast on your background.

## Translate it

Every string a screen reader hears comes from `labels` or from `locale`. See [locale and labels](/essentials/locale).
