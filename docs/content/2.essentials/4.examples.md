Each example assumes `calendarData: {}` in `data()` and the component registered. Dates use the default `dd/mm/yyyy` format.

## Single date

```vue
<FunctionalCalendar v-model="calendarData" :is-date-picker="true" />
```

Read `calendarData.selectedDate`.

## Date range with limits

Users can pick only inside October to December, and ranges between 2 and 14 days.

```vue
<FunctionalCalendar
    v-model="calendarData"
    :is-date-range="true"
    :limits="{ min: '1/10/2026', max: '31/12/2026' }"
    :min-sel-days="2"
    :max-sel-days="14"
    :can-clear-range="true"
/>
```

## Several ranges

```vue
<FunctionalCalendar
    v-model="calendarData"
    :is-date-range="true"
    :is-multiple-date-range="true"
    :can-clear-range="true"
/>
```

Read `calendarData.multipleDateRange`.

## Several single dates

```vue
<FunctionalCalendar v-model="calendarData" :is-multiple-date-picker="true" />
```

Read `calendarData.selectedDates`.

## Two calendars side by side

```vue
<FunctionalCalendar
    v-model="calendarData"
    :is-date-range="true"
    :is-multiple="true"
    :calendars-count="2"
    :is-layout-expandable="true"
/>
```

Add `:is-separately="true"` to let each calendar change month on its own.

## Modal range with inputs

The calendar opens when the inputs gain focus, and closes after a full range.

```vue
<FunctionalCalendar
    v-model="calendarData"
    :is-modal="true"
    :is-date-range="true"
    :is-auto-closeable="true"
    :change-month-function="true"
    :change-year-function="true"
    :date-format="'dd/mm/yyyy'"
/>
```

## Date with time

```vue
<FunctionalCalendar
    v-model="calendarData"
    :is-modal="true"
    :is-date-picker="true"
    :with-time-picker="true"
    :display-time-input="true"
    :active-minutes="[0, 15, 30, 45]"
    date-format="dd/mm/yyyy hh:mm"
/>
```

Read `calendarData.selectedDateTime`, `selectedHour` and `selectedMinute`.

## Disable dates and weekdays

```vue
<FunctionalCalendar
    v-model="calendarData"
    :is-date-picker="true"
    :disabled-dates="['beforeToday', '24/12/2026', '25/12/2026']"
    :disabled-day-names="['Sa', 'Su']"
/>
```

To allow only a list of dates, use `:enabled-dates` instead.

## Mark dates with a class

```vue
<template>
    <FunctionalCalendar v-model="calendarData" :marked-dates="markedDates" />
</template>

<script>
export default {
    data() {
        return {
            calendarData: {},
            markedDates: [
                { date: '17/10/2026', class: 'has-meeting' },
                { date: '24/10/2026', class: 'has-deadline' }
            ]
        }
    }
}
</script>

<style>
.has-meeting {
    background: #dbeafe;
}
.has-deadline {
    background: #fee2e2;
}
</style>
```

## Highlight a span

```vue
<FunctionalCalendar
    v-model="calendarData"
    :marked-date-range="{ start: '5/10/2026', end: '9/10/2026' }"
/>
```

Pass an array of `{ start, end }` objects to highlight more than one span.

## Custom day content

```vue
<template>
    <FunctionalCalendar v-model="calendarData" :is-date-picker="true">
        <template v-slot:default="props">
            <div class="custom-day">
                {{ props.day.day }}
                <small v-if="eventsByDate[props.day.date]">
                    {{ eventsByDate[props.day.date] }}
                </small>
            </div>
        </template>
    </FunctionalCalendar>
</template>

<script>
export default {
    data() {
        return {
            calendarData: {},
            eventsByDate: {
                '17/10/2026': 'Demo',
                '24/10/2026': 'Release'
            }
        }
    }
}
</script>
```

## Translate names

```js
Vue.use(FunctionalCalendar, {
    dayNames: ['Lu', 'Ma', 'Me', 'Je', 'Ve', 'Sa', 'Di'],
    monthNames: [
        'Janvier', 'Février', 'Mars', 'Avril', 'Mai', 'Juin',
        'Juillet', 'Août', 'Septembre', 'Octobre', 'Novembre', 'Décembre'
    ],
    shortMonthNames: [
        'Janv', 'Févr', 'Mars', 'Avr', 'Mai', 'Juin',
        'Juil', 'Août', 'Sept', 'Oct', 'Nov', 'Déc'
    ]
})
```
