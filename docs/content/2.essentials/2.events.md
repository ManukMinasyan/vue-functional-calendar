Listen with `@name` in the template. Event names are camelCase, so write `@dayClicked` or `v-on:dayClicked`. In-DOM templates fold attribute names to lowercase and miss them, so use string templates or single-file components.

| Event | Payload | Fires when |
| --- | --- | --- |
| `input` | calendar object | The selection or the displayed month changes. This powers `v-model`. |
| `dayClicked` | day object | A user clicks any day, even a disabled one or in a calendar with no selection mode. |
| `choseDay` | day object | A click changed the selection. It does not fire for disabled days, days outside `limits` or calendars with no selection mode. |
| `selectedDaysCount` | `Number` | A range is complete. The payload is the number of days between start and end, not counting the first day. |
| `dayMouseOver` | `String` | The pointer enters a day. The payload is the day's date. |
| `changedMonth` | `Date` | The month changes through the arrows or the month picker. |
| `changedYear` | `Date` | The year changes through the arrows or the year picker. |
| `opened` | none | The calendar becomes visible. |
| `closed` | none | The calendar hides. Only modal calendars hide. |

`opened` and `closed` also fire once on mount with the initial state. An inline calendar emits `opened`, and a modal calendar emits `closed`.

## Day object

`dayClicked` and `choseDay` pass an object like this:

```js
{
    day: 17,
    date: '17/10/2026',
    hide: false,
    isMouseToLeft: false,
    isMouseToRight: false,
    isHovered: false,
    isDateRangeStart: false,
    isDateRangeEnd: false,
    hideLeftAndRightDays: false,
    isToday: false,
    isMarked: false
}
```

With `with-time-picker` on a date range, `date` carries a time suffix such as `17/10/2026 00:00`.

## Example

```vue
<template>
    <FunctionalCalendar
        v-model="calendarData"
        :is-date-range="true"
        @selectedDaysCount="days = $event"
        @changedMonth="onChangedMonth"
    />
</template>

<script>
import { FunctionalCalendar } from 'vue-functional-calendar'

export default {
    components: { FunctionalCalendar },
    data() {
        return {
            calendarData: {},
            days: 0
        }
    },
    methods: {
        onChangedMonth(date) {
            console.log(date.getMonth() + 1)
        }
    }
}
</script>
```
