::calendar-demo
---
config:
  isDatePicker: true
  newCurrentDate: '2026-10-01'
  limits:
    min: '8/10/2026'
    max: '24/10/2026'
  disabledDayNames: ['We']
  disabledDates: ['16/10/2026']
---
```vue
<FunctionalCalendar
  v-model="value"
  is-date-picker
  :limits="{ min: '8/10/2026', max: '24/10/2026' }"
  :disabled-day-names="['We']"
  :disabled-dates="['16/10/2026']"
/>
```
::

Dates use `dateFormat`, `dd/mm/yyyy` by default, and need no leading zero.

| Prop | Use |
| --- | --- |
| `limits` | `{ min, max }`. Days outside are disabled and the arrows stop at the edge months. |
| `disabledDates` | A list of dates, plus the keywords `beforeToday` and `afterToday`. |
| `enabledDates` | If it has entries, only those dates (and keywords) can be picked. |
| `disabledDayNames` | Weekday names to disable. They must match `dayNames`, `Mo` to `Su` by default. |
| `minSelDays`, `maxSelDays` | Bounds for the length of a range. |

## Names and locales

With a `locale`, `disabledDayNames` still matches the English two letter names `Mo` to `Su`, as well as the localized ones.

## Reactive list

`enabledDates` is watched. Swap the list to change what is available on a calendar that is on screen. The other props are read once.

## Disabled days and keyboard

A disabled day has `aria-disabled="true"` and stays reachable with the arrow keys. Pressing Enter on it does not select it.

## Presets

A [preset](/essentials/presets#when-a-preset-is-disabled) is disabled when its range breaks one of these rules.
