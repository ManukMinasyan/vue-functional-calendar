Use the `v-slot` syntax from Vue 2.6.

| Slot | Props | Replaces |
| --- | --- | --- |
| `default` | `week`, `day` | The content of each day cell. |
| `navigationArrowLeft` | none | The previous-month arrow. |
| `navigationArrowRight` | none | The next-month arrow. |
| `cleaner` | none | The Clear Range button in the footer. |
| `footer` | none | Extra footer content, shown next to the cleaner. |
| `dateRangeInputs` | `startDate`, `endDate`, `isTypeable` | The two inputs of a modal date range. |
| `datePickerInput` | `selectedDate`, `isTypeable` | The input of a modal date picker. |

The footer renders when `can-clear-range` is on or the `footer` slot is filled.

## Day slot

`day` is the [day object](/essentials/events#day-object) and `week` holds the days of the row. When you fill the slot, the default `vfc-span-day` class no longer applies to the cell. Add `always-use-default-classes` to keep it.

```vue
<FunctionalCalendar v-model="calendarData" :is-date-picker="true">
    <template v-slot:default="props">
        <div class="custom-day">
            {{ props.day.day }}
            <span v-if="props.day.isToday" class="dot"></span>
        </div>
    </template>
</FunctionalCalendar>
```

## Arrows

```vue
<FunctionalCalendar v-model="calendarData">
    <template v-slot:navigationArrowLeft>
        <span>Prev</span>
    </template>
    <template v-slot:navigationArrowRight>
        <span>Next</span>
    </template>
</FunctionalCalendar>
```

## Footer

```vue
<FunctionalCalendar v-model="calendarData" :is-date-range="true" :is-modal="true">
    <template v-slot:cleaner>
        <button type="button">Reset</button>
    </template>
    <template v-slot:footer>
        <button type="button" @click="$refs.calendar.showCalendar = false">Apply</button>
    </template>
</FunctionalCalendar>
```

A click anywhere in the `cleaner` slot clears the selected range. Give the calendar `ref="calendar"` to reach `showCalendar` as the footer example does.

## Inputs

These slots apply to modal calendars only. The slot props are read-only, so the examples bind them with `:value`.

```vue
<FunctionalCalendar v-model="calendarData" :is-date-range="true" :is-modal="true">
    <template v-slot:dateRangeInputs="props">
        <input :value="props.startDate" placeholder="Check in" readonly />
        <input :value="props.endDate" placeholder="Check out" readonly />
    </template>
</FunctionalCalendar>
```

```vue
<FunctionalCalendar v-model="calendarData" :is-date-picker="true" :is-modal="true">
    <template v-slot:datePickerInput="props">
        <input :value="props.selectedDate" placeholder="Pick a date" readonly />
    </template>
</FunctionalCalendar>
```
